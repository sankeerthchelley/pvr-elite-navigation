# PVR Elite — navigation guide

Interactive wayfinding guide for the PVR Elite gated community, Kanuru,
Vijayawada.

Pick a block, or type a flat code (floor × 100 + flat number, so `209` is
floor 2, flat 09). The guide draws the route from the entrance and lists
step-by-step directions through the cellar, lift and floor to the flat.

It is one self-contained page: nothing is loaded from anywhere else, so it
works the same every time.

**Illustrative.** The site map is a schematic and is not drawn to scale.

This is frozen release **v1**. Later versions will be published at separate
paths, so this link never changes.
